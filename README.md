# Tic Tac Toe Plus — Web

Новый веб-клиент игры. Он живёт рядом с Unity-проектом, но собирается отдельно и
не включает Unity, IL2CPP или WebAssembly рантайм.

## Команды

```powershell
npm install
npm run dev
npm test
npm run lint
npm run build
```

Текущая alpha переносит локальный матч: линии длиной 3+, подсчёт уникальных
клеток, очистку фигур, счёт до 20, раунды и рост поля. Также работают стартовая
колода, рука до пяти карт, мана, несколько карт за ход, ручное завершение хода,
случайные фигуры и заморозка клеток.

Остальные карточные эффекты, Photon-мультиплеер, профили и Android-оболочка
подключаются следующими слоями поверх общей TypeScript-логики.
