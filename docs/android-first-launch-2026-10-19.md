# Первый выбор игры в Android

Дата: 2026-10-19. Исходный commit: `135ed1923607a0653b53a742c4cc1e9afd1405b3`.

## Поведение

Первый запуск Android открывает нативные карточки **TTTP / Tic Tac Toe Plus** и **TTTR / Tic Tac Toe Roguelite** до создания игрового WebView. Карточки нарисованы Canvas без растровых ресурсов; слои реагируют на rotation-vector sensor, при его отсутствии экран остаётся доступным. Системное отключение анимаций отключает декоративное движение. Экран учитывает системные панели и вырез, не содержит ScrollView.

Выбор записывается в фоне до перехода в игру. Повторное нажатие во время записи заблокировано; ошибка оставляет возможность повторить выбор. Если приложение свёрнуто во время записи, подтверждение освобождает карточки, а переход ждёт `onResume`. Уничтоженная Activity не получает поздний переход. Повторный запуск с сохранённым выбором не создаёт карточки.

Launcher-компонент MainActivity сохранён. Игра и прежние Capacitor-плагины перенесены в GameActivity; эта Activity не экспортируется. Подписка на сенсор, отложенные кадры, анимации и listeners принадлежат экрану выбора и завершаются при уходе. После подтверждения экран удаляется из view tree, MainActivity завершается. Код классов остаётся установленным в APK: принудительной выгрузки DEX, вызова GC и обещания немедленного возврата всей памяти ОС нет.

## Хранение и совместимость

Новый отдельный native namespace `tttp-world-v1`, ключ `default-world`, принимает только `tttp` / `tttr`. Одна запись является одновременно подтверждением первого выбора и настройкой стартовой игры. Кнопка «Открывать по умолчанию» использует тот же Capacitor-порт; интерфейс сообщает успех только после подтверждения записи. Позднее первоначальное чтение не отменяет более новое переключение игрока.

Существующая установка без этого ключа тоже увидит выбор один раз после обновления. Никакие данные коллекции, экономики, учётной записи или ожидающие операции не мигрируются и не удаляются. Website сохраняет прежний localStorage-ключ `tttp-default-world-v1` и не показывает нативный экран. Между native и localStorage нет зеркальных записей.

Неверное значение не трактуется как завершённый выбор. При неудаче commit сохраняющий порт возвращает ошибку и восстанавливает прежнее значение в памяти; это не заявляется как crash-safe rollback. Прерывание процесса до подтверждения может потребовать повторного выбора. Повторная запись того же выбора допустима. Откат на предыдущую версию оставляет новый native namespace неиспользуемым и использует прежнюю web-настройку; прогресс остаётся на месте. Удаление приложения/очистка данных сбрасывает первый выбор штатным способом, специального удаления файлов или APK-ресурсов нет.
